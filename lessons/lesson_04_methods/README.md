# Урок 4. Методы, декомпозиция и отладка

Предыдущие модули: 1, 2, 3. Рекомендуемый объём: 2–3 встречи по 90 минут и самостоятельная практика.

- Проектировать сигнатуру, входные условия, результат и побочные эффекты
- Различать параметры по значению, ref и out, пользоваться перегрузками и именованными аргументами
- Разделять вычисление и ввод/вывод, отлаживать стек вызовов и проверять контракты

## Маршрут

1. Прочитайте [теорию](THEORY.md); объясните примеры своими словами.
2. Запустите пример, измените один вход и предскажите результат.
3. Откройте [условия](TASKS.md), выберите задачи разных форматов.
4. Пишите в templates/Tasks.cs. Заготовка собирается, но незаполненная задача завершится ошибкой.
5. После своей попытки откройте [подробные решения](SOLUTIONS.md).
6. Проверьте граничный случай и объясните результат.

## Команды из корня курса

```powershell
dotnet run --project "lessons/lesson_04_methods/examples/Урок04.Примеры.csproj"
dotnet run --project "lessons/lesson_04_methods/templates/Урок04.Заготовки.csproj" -- --list
dotnet run --project "lessons/lesson_04_methods/templates/Урок04.Заготовки.csproj" -- 04-01
dotnet run --project "lessons/lesson_04_methods/solutions/Урок04.Решения.csproj" -- 04-01
dotnet run --project "lessons/lesson_04_methods/solutions/Урок04.Решения.csproj" -- --all
```

Третий запуск сообщает NotImplementedException до выполнения работы.
Встроенные проверки решений не исчерпывают все возможные входы.
В ранних модулях классы TaskNN и Run — предоставленный каркас; его устройство изучается в уроке 8.
