# Урок 9. Интерфейсы, наследование и подстановка

Предыдущие модули: 8. Рекомендуемый объём: 2–3 встречи по 90 минут и самостоятельная практика.

- Проектировать контракт и проверять поведение реализаций
- Выбирать интерфейс, абстрактный класс или композицию
- Различать override, new и перегрузку
- Внедрять зависимости вручную и заменять их в тесте

## Маршрут

1. Прочитайте [теорию](THEORY.md); объясните примеры своими словами.
2. Запустите пример, измените один вход и предскажите результат.
3. Откройте [условия](TASKS.md), выберите задачи разных форматов.
4. Пишите в templates/Tasks.cs. Заготовка собирается, но незаполненная задача завершится ошибкой.
5. После своей попытки откройте [подробные решения](SOLUTIONS.md).
6. Проверьте граничный случай и объясните результат.

## Команды из корня курса

```powershell
dotnet run --project "lessons/lesson_09_interfaces/examples/Урок09.Примеры.csproj"
dotnet run --project "lessons/lesson_09_interfaces/templates/Урок09.Заготовки.csproj" -- --list
dotnet run --project "lessons/lesson_09_interfaces/templates/Урок09.Заготовки.csproj" -- 09-01
dotnet run --project "lessons/lesson_09_interfaces/solutions/Урок09.Решения.csproj" -- 09-01
dotnet run --project "lessons/lesson_09_interfaces/solutions/Урок09.Решения.csproj" -- --all
```

Третий запуск сообщает NotImplementedException до выполнения работы.
Встроенные проверки решений не исчерпывают все возможные входы.
В ранних модулях классы TaskNN и Run — предоставленный каркас; его устройство изучается в уроке 8.
