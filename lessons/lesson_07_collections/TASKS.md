## 07-01. Вставка в изменяемый список

Уровень 1 · Реализация · Навык: Индексы List и сдвиг при Insert

Реализуйте public static List&lt;int&gt; InsertCopy(List&lt;int&gt; source, int index, int value). source не null, Count 0..10000, index от 0 до Count включительно. Верните новый список со вставленным value, сохранив порядок. Источник не менять. Позиция Count означает добавление в конец. Входы за указанным диапазоном не подаются.

**Пример и ожидаемое поведение**

<a id="07-04"></a>
## 07-04. Кто следующий в очереди

Уровень 1 · Чтение кода · Навык: FIFO, Peek и Dequeue

Предскажите четыре числа, затем воспроизведите код в public static int[] ReplayQueue(). После Dequeue элемент удаляется, после Peek остаётся. Входов нет; порядок операций менять нельзя.
```csharp
Queue<int> queue = new();
queue.Enqueue(10);
queue.Enqueue(20);
int first = queue.Dequeue();
queue.Enqueue(30);
int next = queue.Peek();
int count = queue.Count;
int second = queue.Dequeue();
// вернуть first, next, count, second
```

**Пример и ожидаемое поведение**

ReplayQueue() -&gt; [10,20,2,20]; в очереди остаётся 30.

## 07-06. Удаление без пропущенного соседа

Уровень 2 · Поиск ошибки · Навык: Изменение индексов List после RemoveAt


## 07-08. Склад: резервирование целиком

Уровень 2 · Реализация · Навык: Двухфазное изменение словаря при бизнес-ограничении

Реализуйте public static bool TryReserve(Dictionary&lt;string,int&gt; stock, Dictionary&lt;string,int&gt; request). stock и request — разные экземпляры словарей, не null, созданные с StringComparer.Ordinal; ключи непустые ASCII, остатки и запрошенные количества в 0..1000000. ## 07-10. Убрать квадратичный поиск допуска

Уровень 2 · Рефакторинг · Навык: Подбор HashSet для многократной проверки членства

Переработайте поиск в public static List&lt;int&gt; FilterAllowed(int[] requested, int[] allowed). Массивы не null, длина каждого 0..100000. Результат содержит разрешённые элементы requested в исходном порядке со всеми их повторами. Повтор allowed ничего не добавляет. Требуется ожидаемое O(n+m), LINQ запрещён. Исходный алгоритм:
```csharp
List<int> result = new();
foreach (int value in requested)
    foreach (int candidate in allowed)
        if (value == candidate) { result.Add(value); break; }
```

**Пример и ожидаемое поведение**

requested=[3,1,3,2], allowed=[3,3,2] -&gt; [3,3,2].
