# Урок 7. Коллекции и выбор структуры данных

Предыдущие модули: 6. Рекомендуемый объём: 2–3 встречи по 90 минут и самостоятельная практика.

- Выбирать List, Dictionary, HashSet, Queue или Stack по операциям
- Сохранять порядок и кратность по условию
- Безопасно изменять коллекцию
- Строить составные алгоритмы без LINQ

## Маршрут

1. Прочитайте [теорию](THEORY.md); объясните примеры своими словами.
2. Запустите пример, измените один вход и предскажите результат.
3. Откройте [условия](TASKS.md), выберите задачи разных форматов.
4. Пишите в templates/Tasks.cs. Заготовка собирается, но незаполненная задача завершится ошибкой.
5. После своей попытки откройте [подробные решения](SOLUTIONS.md).
6. Проверьте граничный случай и объясните результат.

## Команды из корня курса

```powershell
dotnet run --project "lessons/lesson_07_collections/examples/Урок07.Примеры.csproj"
dotnet run --project "lessons/lesson_07_collections/templates/Урок07.Заготовки.csproj" -- --list
dotnet run --project "lessons/lesson_07_collections/templates/Урок07.Заготовки.csproj" -- 07-01
dotnet run --project "lessons/lesson_07_collections/solutions/Урок07.Решения.csproj" -- 07-01
dotnet run --project "lessons/lesson_07_collections/solutions/Урок07.Решения.csproj" -- --all
```

Третий запуск сообщает NotImplementedException до выполнения работы.
Встроенные проверки решений не исчерпывают все возможные входы.
В ранних модулях классы TaskNN и Run — предоставленный каркас; его устройство изучается в уроке 8.
