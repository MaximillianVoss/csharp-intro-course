# Урок 11. JSON и контракты данных

Предыдущие модули: 8, 9, 10. Рекомендуемый объём: 2–3 встречи по 90 минут и самостоятельная практика.

- Сериализовать объекты без ручного экранирования
- Различать синтаксис JSON и правила предметной области
- Обрабатывать null, отсутствующие поля и версии формата
- Проверять импорт до изменения состояния

## Маршрут

1. Прочитайте [теорию](THEORY.md); объясните примеры своими словами.
2. Запустите пример, измените один вход и предскажите результат.
3. Откройте [условия](TASKS.md), выберите задачи разных форматов.
4. Пишите в templates/Tasks.cs. Заготовка собирается, но незаполненная задача завершится ошибкой.
5. После своей попытки откройте [подробные решения](SOLUTIONS.md).
6. Проверьте граничный случай и объясните результат.

## Команды из корня курса

```powershell
dotnet run --project "lessons/lesson_11_json/examples/Урок11.Примеры.csproj"
dotnet run --project "lessons/lesson_11_json/templates/Урок11.Заготовки.csproj" -- --list
dotnet run --project "lessons/lesson_11_json/templates/Урок11.Заготовки.csproj" -- 11-01
dotnet run --project "lessons/lesson_11_json/solutions/Урок11.Решения.csproj" -- 11-01
dotnet run --project "lessons/lesson_11_json/solutions/Урок11.Решения.csproj" -- --all
```

Третий запуск сообщает NotImplementedException до выполнения работы.
Встроенные проверки решений не исчерпывают все возможные входы.
В ранних модулях классы TaskNN и Run — предоставленный каркас; его устройство изучается в уроке 8.
