# Урок 1. Первая программа, типы и выражения

Предыдущие модули: не требуются. Рекомендуемый объём: 2–3 встречи по 90 минут и самостоятельная практика.

- Собирать консольную программу и отличать ошибку компиляции от неверного результата
- Выбирать int, long, double, decimal, bool и string под данные
- Предсказывать порядок вычислений и явно управлять преобразованиями и переполнением

## Маршрут

1. Прочитайте [теорию](THEORY.md); объясните примеры своими словами.
2. Запустите пример, измените один вход и предскажите результат.
3. Откройте [условия](TASKS.md), выберите задачи разных форматов.
4. Пишите в templates/Tasks.cs. Заготовка собирается, но незаполненная задача завершится ошибкой.
5. После своей попытки откройте [подробные решения](SOLUTIONS.md).
6. Проверьте граничный случай и объясните результат.

## Команды из корня курса

```powershell
dotnet run --project "lessons/lesson_01_basics/examples/Урок01.Примеры.csproj"
dotnet run --project "lessons/lesson_01_basics/templates/Урок01.Заготовки.csproj" -- --list
dotnet run --project "lessons/lesson_01_basics/templates/Урок01.Заготовки.csproj" -- 01-01
dotnet run --project "lessons/lesson_01_basics/solutions/Урок01.Решения.csproj" -- 01-01
dotnet run --project "lessons/lesson_01_basics/solutions/Урок01.Решения.csproj" -- --all
```

Третий запуск сообщает NotImplementedException до выполнения работы.
Встроенные проверки решений не исчерпывают все возможные входы.
В ранних модулях классы TaskNN и Run — предоставленный каркас; его устройство изучается в уроке 8.
