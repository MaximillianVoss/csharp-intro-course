## 01-01. Подпись складской ячейки

Уровень 1 · Реализация · Навык: Типы параметров и интерполяция без потери данных

В предоставленном каркасе заполните тело `string Label(string item, int count)`.
Верните ровно `товар: количество шт.` с одним пробелом после двоеточия.
`item` — непустая строка без переводов строк, `count` от 0 до 1 000 000.
Данные вне этих предусловий не передаются. Не печатайте из метода и не меняйте имя товара.

**Пример и ожидаемое поведение**

`Label("Кабель", 12)` → `"Кабель: 12 шт."`; ноль → `"Кабель: 0 шт."`.

<a id="01-02"></a>
## 01-02. Разложение длительности

Уровень 1 · Реализация · Навык: Согласование целого деления и остатка

Заполните тело `string Duration(int seconds)`. `seconds` — целое от 0 до 1 000 000.
Верните `H:M:S` без ведущих нулей: H — полные часы, M от 0 до 59, S от 0 до 59.
Нельзя использовать DateTime или TimeSpan: цель — операции `/` и `%`.
Вне указанного диапазона метод не вызывается; дополнительных проверок не требуется.

**Пример и ожидаемое поведение**

`Duration(3661)` → `"1:1:1"`; `Duration(3599)` → `"0:59:59"`.

<a id="01-03"></a>
## 01-03. Дробь исчезла до присваивания

Уровень 1 · Чтение кода · Навык: Тип выражения определяется операндами, а не получателем

В контексте готового метода дан код:
```csharp
public static double Truncated(int total, int count)
{
    double mean = total / count;
    return mean;
}
```
Без запуска предскажите результат `Truncated(7, 2)` и объясните причину.
Затем реализуйте `double Mean(int total, int count)`, сохраняющий дробную часть.
total от -1 000 000 до 1 000 000, count от 1 до 1 000 000. Вне диапазонов вызовов нет.
В проверке выполните и исходный, и исправленный вариант.

**Пример и ожидаемое поведение**

`Truncated(7, 2)` → `3.0`; требуемый `Mean(7, 2)` → `3.5`.

## 01-04. Десятичная скидка

Уровень 1 · Реализация · Навык: Десятичные литералы и денежное выражение

Заполните `decimal Discounted(decimal unitPrice, int quantity, decimal percent)`.
unitPrice от 0 до 1 000 000, quantity от 0 до 1000, percent от 0 до 100 включительно.
Верните точную вычисленную decimal-сумму после процентной скидки без округления до копеек.
Входы удовлетворяют ограничениям; дополнительная валидация не нужна. double не используйте.

**Пример и ожидаемое поведение**

`Discounted(19.90m, 3, 10m)` → `53.73m`; скидка 100% → `0m`.

## 01-05. Скорость с единицами измерения

Уровень 1 · Реализация · Навык: Проверка размерности вещественного выражения

Реализуйте `double KilometresPerHour(double metres, double seconds)`.
metres — конечное число от 0 до 1 000 000, seconds — конечное число от 0.1 до 100 000.
Верните среднюю скорость в км/ч без округления для показа; при сравнении допустима погрешность 1e-8.
На входе нет NaN и бесконечностей; данные вне диапазонов не передаются.

**Пример и ожидаемое поведение**

`KilometresPerHour(100, 20)` → `18`; `KilometresPerHour(1500, 120)` → `45`.

## 01-06. Пошаговое состояние двух переменных

Уровень 2 · Чтение кода · Навык: Последовательность присваиваний и текущие значения

Дан метод в каркасе:
```csharp
public static string Trace(int start)
{
    int x = start;
    int y = x + 2;
    x = y * 3;
    y = x - y;
    return $"{x}:{y}";
}
```
Для start=4 составьте таблицу x,y после каждой строки и назовите возвращаемый текст.
Воспроизведите данный метод без изменения порядка строк. start от -1000 до 1000;
вне диапазона вызовов нет. Затем проверьте ответ выполнением на 4, 0 и -2.

**Пример и ожидаемое поведение**

`Trace(4)` → `"18:12"`; `Trace(-2)` → `"0:0"`.

## 01-07. Расширение произошло слишком поздно

Уровень 2 · Поиск ошибки · Навык: Промежуточный тип умножения и приведение перед операцией

Исправьте метод:
```csharp
public static long Area(int width, int height)
{
    long area = unchecked(width * height);
    return area;
}
```
Требуемая сигнатура остаётся `long Area(int width, int height)`.
width,height от 0 до int.MaxValue. Верните математически точное произведение;
вне диапазона вызовов нет. Укажите результат исходника на 50000,50000 и причину ошибки.

**Пример и ожидаемое поведение**

Исходник на (50000,50000) → `-1794967296`; исправленный Area → `2500000000L`.

## 01-08. Var не меняет тип переменной

Уровень 2 · Поиск ошибки · Навык: Статический вывод типа и ошибка компиляции при присваивании

Этот фрагмент находится внутри метода:
```csharp
var value = start;
value = value * 1.5;
return value;
```
start имеет тип int. Объясните, почему код не компилируется, и напишите рабочий
`double Increased(int start)` с теми же двумя шагами: объявление value и увеличение в 1.5 раза.
start от -1 000 000 до 1 000 000; вне диапазона вызовов нет. Не отбрасывайте дробную часть.

**Пример и ожидаемое поведение**

`Increased(3)` → `4.5`; `Increased(-3)` → `-4.5`.

## 01-10. Остаток со знаком

Уровень 2 · Чтение кода · Навык: Деление отрицательных целых и тождество частного и остатка

Дан код:
```csharp
public static string Parts(int a, int b)
{
    return $"{a / b}:{a % b}";
}
```
Предскажите текст для (-7,3), (7,-3), (-7,-3). Воспроизведите метод и проверьте прогноз.
a и b от -1000 до 1000, b не равен 0; вне этих предусловий вызовов нет.
Запишите для каждого примера равенство a = (a/b)*b + a%b.

**Пример и ожидаемое поведение**

`Parts(-7, 3)` → `"-2:-1"`; `Parts(7, -3)` → `"-2:1"`.

## 01-11. Тест округления на половине

Уровень 3 · Проектирование тестов · Навык: Выбор различающего теста для политики округления decimal

Нужно проверить `decimal RoundMoney(decimal amount)`: округление до двух десятичных знаков,
точная середина округляется от нуля. amount от -1 000 000 до 1 000 000.
Вне диапазона вызовов нет. В каркасе уже доступны `Math.Round` и именованный режим
`MidpointRounding.AwayFromZero`; это готовый параметр библиотечного вызова.
Напишите не менее четырёх исполняемых проверок и покажите, что хотя бы одна выявляет
ошибочный вариант `Math.Round(amount, 2)` без явного режима. Реализуйте правильный метод.

**Пример и ожидаемое поведение**

`RoundMoney(2.345m)` → `2.35m`; `RoundMoney(-2.345m)` → `-2.35m`.

## 01-12. Явный контроль переполнения суммы

Уровень 3 · Чтение кода · Навык: Отличие checked от unchecked для int

Даны два тела методов с одинаковыми параметрами int a,b:
```csharp
// CheckedSum
return checked(a + b);
// WrappedSum
return unchecked(a + b);
```
Реализуйте `int CheckedSum(int a, int b)` и `int WrappedSum(int a, int b)` буквально.
Предскажите поведение для (int.MaxValue,1), (int.MinValue,-1) и (20,22).
Допустимы любые int. Переполнение первого метода должно приводить к OverflowException;
проверку этого события предоставляет Check.Throws, писать обработчик исключений пока не нужно.

**Пример и ожидаемое поведение**

`CheckedSum(20,22)` → `42`; `WrappedSum(int.MaxValue,1)` → `int.MinValue`.

## 01-13. Сравнение измерения с допуском

Уровень 3 · Реализация · Навык: Приближённое сравнение конечных double по абсолютной ошибке

Реализуйте `bool Within(double measured, double expected, double tolerance)`.
Все числа конечны, measured и expected от -1 000 000 до 1 000 000, tolerance от 0 до 100.
Верните true, если абсолютная разность не превосходит tolerance, иначе false.
Граница включена. NaN и бесконечности не передаются; вне диапазонов вызовов нет.
Используйте библиотечный модуль Math.Abs; округление для экрана не является сравнением.

**Пример и ожидаемое поведение**

`Within(9.5, 10, 0.5)` → `true`; `Within(9.49, 10, 0.5)` → `false`.

## 01-14. Сужение числа до байта

Уровень 3 · Реализация · Навык: Явное проверяемое преобразование диапазона int в byte

Заполните `byte Channel(int value)`. При value от 0 до 255 включительно
верните то же значение как byte. Для любого другого int должна возникнуть OverflowException.
Используйте checked-преобразование, а не ветвления: byte — целое число от 0 до 255.
Check.Throws в каркасе проверяет ожидаемый отказ; обработку исключений писать не требуется.

**Пример и ожидаемое поведение**

`Channel(255)` → `(byte)255`; `Channel(256)` и `Channel(-1)` → OverflowException.

## 01-15. План покупки краски

Уровень 3 · Прикладная задача · Навык: Сборка вычислительного конвейера и округление вверх по смыслу

Реализуйте `int Cans(double width, double height, double coverage)` для одной прямоугольной стены.
width,height — конечные числа от 0 до 10 000 метров, coverage — конечное число от 0.1 до 10 000 м² на банку.
Требуется покрыть всю стену одним слоем без вычета проёмов; верните минимальное целое число целых банок.
Нулевая площадь требует ноль банок. Входы удовлетворяют ограничениям, NaN и бесконечностей нет.
Доступен Math.Ceiling, возвращающий ближайшее целое double вверх; явно преобразуйте результат в int.
Не округляйте площадь на промежуточном шаге.

**Пример и ожидаемое поведение**

`Cans(4, 2.5, 3)` → `4`; `Cans(3, 2, 3)` → `2`; нулевая ширина → `0`.
