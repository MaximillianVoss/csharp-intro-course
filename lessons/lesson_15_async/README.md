# Урок 15. Асинхронность, отмена и потоки данных

Предыдущие модули: 10, 11, 12, 13, 14. Рекомендуемый объём: 2–3 встречи по 90 минут и самостоятельная практика.

- Возвращать Task, представляющий всю работу
- Проверять порядок через управляемые завершения
- Передавать CancellationToken и освобождать ресурсы
- Ограничивать параллельные операции и потоковый импорт

## Маршрут

1. Прочитайте [теорию](THEORY.md); объясните примеры своими словами.
2. Запустите пример, измените один вход и предскажите результат.
3. Откройте [условия](TASKS.md), выберите задачи разных форматов.
4. Пишите в templates/Tasks.cs. Заготовка собирается, но незаполненная задача завершится ошибкой.
5. После своей попытки откройте [подробные решения](SOLUTIONS.md).
6. Проверьте граничный случай и объясните результат.

## Команды из корня курса

```powershell
dotnet run --project "lessons/lesson_15_async/examples/Урок15.Примеры.csproj"
dotnet run --project "lessons/lesson_15_async/templates/Урок15.Заготовки.csproj" -- --list
dotnet run --project "lessons/lesson_15_async/templates/Урок15.Заготовки.csproj" -- 15-01
dotnet run --project "lessons/lesson_15_async/solutions/Урок15.Решения.csproj" -- 15-01
dotnet run --project "lessons/lesson_15_async/solutions/Урок15.Решения.csproj" -- --all
```

Третий запуск сообщает NotImplementedException до выполнения работы.
Встроенные проверки решений не исчерпывают все возможные входы.
В ранних модулях классы TaskNN и Run — предоставленный каркас; его устройство изучается в уроке 8.
