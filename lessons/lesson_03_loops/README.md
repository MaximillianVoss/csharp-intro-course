# Урок 3. Циклы, состояния и численные алгоритмы

Предыдущие модули: 1, 2. Рекомендуемый объём: 2–3 встречи по 90 минут и самостоятельная практика.

- Выбирать for, while и do/while и объяснять условие завершения
- Формулировать инвариант и проверять границы до и после итерации
- Работать с потоком строк без массивов, обрабатывать EOF и ограничивать число попыток

## Маршрут

1. Прочитайте [теорию](THEORY.md); объясните примеры своими словами.
2. Запустите пример, измените один вход и предскажите результат.
3. Откройте [условия](TASKS.md), выберите задачи разных форматов.
4. Пишите в templates/Tasks.cs. Заготовка собирается, но незаполненная задача завершится ошибкой.
5. После своей попытки откройте [подробные решения](SOLUTIONS.md).
6. Проверьте граничный случай и объясните результат.

## Команды из корня курса

```powershell
dotnet run --project "lessons/lesson_03_loops/examples/Урок03.Примеры.csproj"
dotnet run --project "lessons/lesson_03_loops/templates/Урок03.Заготовки.csproj" -- --list
dotnet run --project "lessons/lesson_03_loops/templates/Урок03.Заготовки.csproj" -- 03-01
dotnet run --project "lessons/lesson_03_loops/solutions/Урок03.Решения.csproj" -- 03-01
dotnet run --project "lessons/lesson_03_loops/solutions/Урок03.Решения.csproj" -- --all
```

Третий запуск сообщает NotImplementedException до выполнения работы.
Встроенные проверки решений не исчерпывают все возможные входы.
В ранних модулях классы TaskNN и Run — предоставленный каркас; его устройство изучается в уроке 8.
