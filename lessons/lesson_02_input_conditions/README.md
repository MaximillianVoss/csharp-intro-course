# Урок 2. Ввод, условия и выбор действия

Предыдущие модули: 1. Рекомендуемый объём: 2–3 встречи по 90 минут и самостоятельная практика.

- Различать EOF, пустую строку, ошибочный формат и недопустимое значение
- Использовать TryParse, if и switch без падения на обычной ошибке ввода
- Проверять границы, логические выражения и приоритет правил

## Маршрут

1. Прочитайте [теорию](THEORY.md); объясните примеры своими словами.
2. Запустите пример, измените один вход и предскажите результат.
3. Откройте [условия](TASKS.md), выберите задачи разных форматов.
4. Пишите в templates/Tasks.cs. Заготовка собирается, но незаполненная задача завершится ошибкой.
5. После своей попытки откройте [подробные решения](SOLUTIONS.md).
6. Проверьте граничный случай и объясните результат.

## Команды из корня курса

```powershell
dotnet run --project "lessons/lesson_02_input_conditions/examples/Урок02.Примеры.csproj"
dotnet run --project "lessons/lesson_02_input_conditions/templates/Урок02.Заготовки.csproj" -- --list
dotnet run --project "lessons/lesson_02_input_conditions/templates/Урок02.Заготовки.csproj" -- 02-01
dotnet run --project "lessons/lesson_02_input_conditions/solutions/Урок02.Решения.csproj" -- 02-01
dotnet run --project "lessons/lesson_02_input_conditions/solutions/Урок02.Решения.csproj" -- --all
```

Третий запуск сообщает NotImplementedException до выполнения работы.
Встроенные проверки решений не исчерпывают все возможные входы.
В ранних модулях классы TaskNN и Run — предоставленный каркас; его устройство изучается в уроке 8.
