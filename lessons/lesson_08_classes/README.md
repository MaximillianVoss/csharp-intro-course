# Урок 8. Классы, свойства, инварианты и композиция

Предыдущие модули: 6, 7. Рекомендуемый объём: 2–3 встречи по 90 минут и самостоятельная практика.

- Проектировать объект с сохраняемым инвариантом
- Различать ссылку, значение и копирование графа
- Использовать неизменяемые record и композицию
- Защищать внутреннее состояние на границе класса

## Маршрут

1. Прочитайте [теорию](THEORY.md); объясните примеры своими словами.
2. Запустите пример, измените один вход и предскажите результат.
3. Откройте [условия](TASKS.md), выберите задачи разных форматов.
4. Пишите в templates/Tasks.cs. Заготовка собирается, но незаполненная задача завершится ошибкой.
5. После своей попытки откройте [подробные решения](SOLUTIONS.md).
6. Проверьте граничный случай и объясните результат.

## Команды из корня курса

```powershell
dotnet run --project "lessons/lesson_08_classes/examples/Урок08.Примеры.csproj"
dotnet run --project "lessons/lesson_08_classes/templates/Урок08.Заготовки.csproj" -- --list
dotnet run --project "lessons/lesson_08_classes/templates/Урок08.Заготовки.csproj" -- 08-01
dotnet run --project "lessons/lesson_08_classes/solutions/Урок08.Решения.csproj" -- 08-01
dotnet run --project "lessons/lesson_08_classes/solutions/Урок08.Решения.csproj" -- --all
```

Третий запуск сообщает NotImplementedException до выполнения работы.
Встроенные проверки решений не исчерпывают все возможные входы.
В ранних модулях классы TaskNN и Run — предоставленный каркас; его устройство изучается в уроке 8.
