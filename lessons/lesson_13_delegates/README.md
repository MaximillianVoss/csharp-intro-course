# Урок 13. Делегаты, лямбды и события

Предыдущие модули: 8, 9, 12. Рекомендуемый объём: 2–3 встречи по 90 минут и самостоятельная практика.

- Передавать поведение через Func/Action/Predicate
- Объяснять захват переменной и момент вызова
- Компоновать и тестировать стратегии
- Различать делегат и событие

## Маршрут

1. Прочитайте [теорию](THEORY.md); объясните примеры своими словами.
2. Запустите пример, измените один вход и предскажите результат.
3. Откройте [условия](TASKS.md), выберите задачи разных форматов.
4. Пишите в templates/Tasks.cs. Заготовка собирается, но незаполненная задача завершится ошибкой.
5. После своей попытки откройте [подробные решения](SOLUTIONS.md).
6. Проверьте граничный случай и объясните результат.

## Команды из корня курса

```powershell
dotnet run --project "lessons/lesson_13_delegates/examples/Урок13.Примеры.csproj"
dotnet run --project "lessons/lesson_13_delegates/templates/Урок13.Заготовки.csproj" -- --list
dotnet run --project "lessons/lesson_13_delegates/templates/Урок13.Заготовки.csproj" -- 13-01
dotnet run --project "lessons/lesson_13_delegates/solutions/Урок13.Решения.csproj" -- 13-01
dotnet run --project "lessons/lesson_13_delegates/solutions/Урок13.Решения.csproj" -- --all
```

Третий запуск сообщает NotImplementedException до выполнения работы.
Встроенные проверки решений не исчерпывают все возможные входы.
В ранних модулях классы TaskNN и Run — предоставленный каркас; его устройство изучается в уроке 8.
