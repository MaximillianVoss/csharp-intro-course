# Урок 12. Обобщённые типы и алгоритмы

Предыдущие модули: 7, 8, 9. Рекомендуемый объём: 2–3 встречи по 90 минут и самостоятельная практика.

- Различать параметр типа и значение
- Выражать ограничения where
- Строить типобезопасные контейнеры
- Проверять пустоту и default без потери данных

## Маршрут

1. Прочитайте [теорию](THEORY.md); объясните примеры своими словами.
2. Запустите пример, измените один вход и предскажите результат.
3. Откройте [условия](TASKS.md), выберите задачи разных форматов.
4. Пишите в templates/Tasks.cs. Заготовка собирается, но незаполненная задача завершится ошибкой.
5. После своей попытки откройте [подробные решения](SOLUTIONS.md).
6. Проверьте граничный случай и объясните результат.

## Команды из корня курса

```powershell
dotnet run --project "lessons/lesson_12_generics/examples/Урок12.Примеры.csproj"
dotnet run --project "lessons/lesson_12_generics/templates/Урок12.Заготовки.csproj" -- --list
dotnet run --project "lessons/lesson_12_generics/templates/Урок12.Заготовки.csproj" -- 12-01
dotnet run --project "lessons/lesson_12_generics/solutions/Урок12.Решения.csproj" -- 12-01
dotnet run --project "lessons/lesson_12_generics/solutions/Урок12.Решения.csproj" -- --all
```

Третий запуск сообщает NotImplementedException до выполнения работы.
Встроенные проверки решений не исчерпывают все возможные входы.
В ранних модулях классы TaskNN и Run — предоставленный каркас; его устройство изучается в уроке 8.
