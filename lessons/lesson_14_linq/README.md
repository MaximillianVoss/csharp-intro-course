# Урок 14. LINQ и обработка последовательностей

Предыдущие модули: 7, 12, 13. Рекомендуемый объём: 2–3 встречи по 90 минут и самостоятельная практика.

- Строить запросы фильтрации, проекции и группировки
- Отличать отложенный запрос от снимка
- Задавать политику пустоты и дубликатов
- Обосновывать порядок, число обходов и сложность

## Маршрут

1. Прочитайте [теорию](THEORY.md); объясните примеры своими словами.
2. Запустите пример, измените один вход и предскажите результат.
3. Откройте [условия](TASKS.md), выберите задачи разных форматов.
4. Пишите в templates/Tasks.cs. Заготовка собирается, но незаполненная задача завершится ошибкой.
5. После своей попытки откройте [подробные решения](SOLUTIONS.md).
6. Проверьте граничный случай и объясните результат.

## Команды из корня курса

```powershell
dotnet run --project "lessons/lesson_14_linq/examples/Урок14.Примеры.csproj"
dotnet run --project "lessons/lesson_14_linq/templates/Урок14.Заготовки.csproj" -- --list
dotnet run --project "lessons/lesson_14_linq/templates/Урок14.Заготовки.csproj" -- 14-01
dotnet run --project "lessons/lesson_14_linq/solutions/Урок14.Решения.csproj" -- 14-01
dotnet run --project "lessons/lesson_14_linq/solutions/Урок14.Решения.csproj" -- --all
```

Третий запуск сообщает NotImplementedException до выполнения работы.
Встроенные проверки решений не исчерпывают все возможные входы.
В ранних модулях классы TaskNN и Run — предоставленный каркас; его устройство изучается в уроке 8.
