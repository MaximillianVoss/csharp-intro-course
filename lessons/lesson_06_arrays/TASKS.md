## 06-01. Первый максимум

Уровень 1 · Реализация · Навык: Инвариант линейного поиска и правило равенства

Реализуйте public static int FirstMaximumIndex(int[] values). Массив не null, длина 0..100000, значения любые int. Верните индекс первого максимального элемента; для пустого массива верните -1. Массив не изменяйте. При нескольких максимумах выбирайте самый левый.

**Пример и ожидаемое поведение**

[3, 8, 8, -2] -> 1; [] -> -1.

## 06-02. Псевдоним и независимая копия

Уровень 1 · Чтение кода · Навык: Ссылочная семантика массива и Clone

Предскажите результат Replay и объясните каждое изменение. Затем воспроизведите фрагмент в public static int[] Replay(), который возвращает три указанных значения. Изменять заданную последовательность действий нельзя. Дополнительного ввода нет.
```csharp
int[] a = { 2, 4 };
int[] alias = a;
int[] copy = (int[])a.Clone();
alias[0] = 9;
copy[1] = 7;
// результат: a[0], a[1], copy[1]
```

**Пример и ожидаемое поведение**

Replay() -> [9, 4, 7].

## 06-03. Последний допустимый индекс

Уровень 1 · Поиск ошибки · Навык: Поиск ошибки границы цикла

Найдите ошибку и исправьте метод public static long Sum(int[] values). Массив не null, длина 0..100000, элементы любые int; сумма должна вычисляться в long, пустой массив даёт 0. Объясните, какой индекс первым нарушит границу в исходном фрагменте; затем проверьте исправление.
```csharp
long total = 0;
for (int i = 0; i <= values.Length; i++)
    total += values[i];
```

**Пример и ожидаемое поведение**

[5, -2, 7] -> 10; [] -> 0; [int.MaxValue, int.MaxValue] -> 4294967294.

## 06-14. Перекрывающийся сдвиг

Уровень 3 · Поиск ошибки · Навык: Направление копирования при перекрытии областей

Исправьте алгоритм public static void ShiftRight(int[] values, int places), который сдвигает элементы вправо с потерей хвоста, а освободившиеся места заполняет нулями. values не null, длина 0..100000; places в 0..Length. Выполните и объясните ошибочный фрагмент при [1,2,3,4], places=1. Затем реализуйте исправление без второго массива.
```csharp
for (int i = places; i < values.Length; i++)
    values[i] = values[i - places];
for (int i = 0; i < places; i++) values[i] = 0;
```

**Пример и ожидаемое поведение**

Исправленный: [1,2,3,4],1 -> [0,1,2,3]; places=Length -> все нули.
