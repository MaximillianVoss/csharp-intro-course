# Урок 6. Массивы, индексы и алгоритмы поиска

Предыдущие модули: 4, 5. Рекомендуемый объём: 2–3 встречи по 90 минут и самостоятельная практика.

- Выбирать границы циклов и сохранять инвариант
- Различать копию массива и общую ссылку
- Работать с прямоугольными матрицами
- Сравнивать линейный и бинарный поиск

## Маршрут

1. Прочитайте [теорию](THEORY.md); объясните примеры своими словами.
2. Запустите пример, измените один вход и предскажите результат.
3. Откройте [условия](TASKS.md), выберите задачи разных форматов.
4. Пишите в templates/Tasks.cs. Заготовка собирается, но незаполненная задача завершится ошибкой.
5. После своей попытки откройте [подробные решения](SOLUTIONS.md).
6. Проверьте граничный случай и объясните результат.

## Команды из корня курса

```powershell
dotnet run --project "lessons/lesson_06_arrays/examples/Урок06.Примеры.csproj"
dotnet run --project "lessons/lesson_06_arrays/templates/Урок06.Заготовки.csproj" -- --list
dotnet run --project "lessons/lesson_06_arrays/templates/Урок06.Заготовки.csproj" -- 06-01
dotnet run --project "lessons/lesson_06_arrays/solutions/Урок06.Решения.csproj" -- 06-01
dotnet run --project "lessons/lesson_06_arrays/solutions/Урок06.Решения.csproj" -- --all
```

Третий запуск сообщает NotImplementedException до выполнения работы.
Встроенные проверки решений не исчерпывают все возможные входы.
В ранних модулях классы TaskNN и Run — предоставленный каркас; его устройство изучается в уроке 8.
