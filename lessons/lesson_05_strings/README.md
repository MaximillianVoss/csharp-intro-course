# Урок 5. Строки, сравнение и границы Unicode

Предыдущие модули: 1, 2, 3, 4. Рекомендуемый объём: 2–3 встречи по 90 минут и самостоятельная практика.

- Безопасно индексировать и выделять части строк, помнить о неизменяемости
- Выбирать ordinal-сравнение для протокола и явную культуру для пользовательских чисел
- Различать char UTF-16, Rune и текстовый элемент StringInfo и проверять Unicode-границы

## Маршрут

1. Прочитайте [теорию](THEORY.md); объясните примеры своими словами.
2. Запустите пример, измените один вход и предскажите результат.
3. Откройте [условия](TASKS.md), выберите задачи разных форматов.
4. Пишите в templates/Tasks.cs. Заготовка собирается, но незаполненная задача завершится ошибкой.
5. После своей попытки откройте [подробные решения](SOLUTIONS.md).
6. Проверьте граничный случай и объясните результат.

## Команды из корня курса

```powershell
dotnet run --project "lessons/lesson_05_strings/examples/Урок05.Примеры.csproj"
dotnet run --project "lessons/lesson_05_strings/templates/Урок05.Заготовки.csproj" -- --list
dotnet run --project "lessons/lesson_05_strings/templates/Урок05.Заготовки.csproj" -- 05-01
dotnet run --project "lessons/lesson_05_strings/solutions/Урок05.Решения.csproj" -- 05-01
dotnet run --project "lessons/lesson_05_strings/solutions/Урок05.Решения.csproj" -- --all
```

Третий запуск сообщает NotImplementedException до выполнения работы.
Встроенные проверки решений не исчерпывают все возможные входы.
В ранних модулях классы TaskNN и Run — предоставленный каркас; его устройство изучается в уроке 8.
