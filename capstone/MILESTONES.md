# Итоговое приложение: этапы самостоятельной работы

Условия находятся в SPEC.md. Здесь нет готовой реализации.

## 1. Модель и тест-план

Создайте решение с библиотекой, консольным и MSTest-проектом.
Опишите Book и операции каталога в памяти; до написания хранения составьте таблицу границ.
Проверьте Trim, пустое название, нижний/верхний год, корректную суррогатную пару,
отказ на непарных суррогатах в обоих текстовых полях, повторное прочтение и неизвестный ID.
Готовность: изменение книги возможно только через оговорённые операции; ошибочное добавление не расходует ID.

## 2. Коллекция и команды в памяти

Реализуйте добавление, поиск, отметку, удаление, статистику.
Проверьте два одинаковых названия, удаление и следующее добавление.
Готовность: новый ID больше ранее выданных, список имеет стабильный порядок, поиск объяснимо учитывает регистр.

## 3. CLI без настоящего файла

Отделите разбор аргументов, выполнение операции и вывод.
Передавайте TextWriter и тестовое хранилище.
Проверьте неизвестную команду, пропущенный аргумент и отсутствие сообщения об успехе при отказе save.
Готовность: неверная грамматика не вызывает загрузку, код завершения соответствует SPEC.md.

## 4. JSON и файловые ошибки

Введите DTO снимка, schemaVersion и nextId.
Отделите десериализацию от проверки предметных ограничений.
Тестируйте отсутствующий, пустой, повреждённый и корректный файл, повтор ID, null и неверный nextId.
Все испытания выполняются в отдельном временном каталоге.
Готовность: повреждённый файл остаётся в исходном виде, корректный каталог загружается новым экземпляром.

## 5. Асинхронность и отмена

Добавьте async IO и CancellationToken.
Запись проходит через временный файл рядом с целевым.
Проверьте уже отменённую операцию и отсутствие оставшихся временных файлов.
Готовность: отмена не превращается в успех, сообщение появляется после успешной фиксации.
Объясните ограничение одного процесса записи.

## 6. Приёмка и защита

Запустите тесты и сценарий CLI в чистой копии.
Добавьте книгу, перезапустите процесс, отметьте прочтение, найдите её, выведите статистику и удалите.
Создайте повреждённый файл только в своей временной папке и покажите понятную ошибку.
Подготовьте краткую инструкцию: SDK, сборка, команды, коды завершения и известные ограничения.
Попросите преподавателя выбрать одно небольшое изменение и сначала уточните его контракт.

Готовое решение находится рядом для сравнения после собственной реализации.
Заготовки отдельных задач уроков не являются готовым итоговым приложением.
