# Карточки для виртуального репетитора

Курс содержит 240 заданий с постоянными ID `01-01`…`16-15`.
Глобальный ключ — `csharp-intro-course:01-01`. Название, формулировка и код могут
уточняться без смены ключа; `content_sha256` отличает редакции одного задания.

После сборки и содержательной проверки выполните из корня:

```powershell
python tools/export_cards.py --verify-starters --source-version <COMMIT_SHA>
```

В `artifacts/cards` появятся:

- `learner.cards.jsonl`: условие, пример, предметный незаполненный код и требования среды;
- `teacher.cards.jsonl`: ответы, объяснения, эталонный код, проверки и запись рецензии;
- `manifest.json`: версия, количество, хеши и статус компиляции извлечённых заготовок.

Ученическая карточка не содержит полей решения. Для показа задания используйте
только learner-файл. Teacher-файл храните отдельно; его данные можно выдавать
согласно педагогическому сценарию после попытки ученика. Репозиторий публичный,
поэтому это разделение учебных материалов, а не защита экзаменационных секретов.

`source_directory` задаёт базу относительных ссылок в условии. В частности,
16-15 требует документов `capstone/SPEC.md` и `capstone/PUBLIC_API.md`; перенос
одного текста карточки без этих документов делает её неполной.

Среда: .NET 10, C# 14, nullable и implicit usings. К каждому фрагменту заготовки
нужен `shared/Check.cs`; уроку 16 также нужна ссылка на `Библиотека.Ядро`.
Для урока 15 метод `Run` возвращает `Task`, и его нужно ожидать. В остальных
уроках он возвращает `void`. Каждый из 240 фрагментов компилируется отдельно
как библиотека, с указанными зависимостями и без кода остальных заданий.
Незаполненный `Run` по-прежнему выбрасывает `NotImplementedException`.

Эталонные `Run` исполняют проверки эталонного кода. Они не являются готовым
адаптером автоматической оценки произвольного кода ученика: для этого требуется
отдельное связывание контрактов, проверок и присланной реализации. Импорт данных
не доказывает работоспособность C#-исполнителя, изоляции файлов/процессов,
ограничений времени и памяти либо интерфейса репетитора.

Для безопасной интеграции сначала проверьте схему и хеши, покажите ученическую
карточку, сохраните попытку с её `content_sha256`, затем отдельно подключайте и
проверяйте исполнитель. Не заявляйте запуск C# доступным до его фактической
проверки в среде репетитора.

## Поддержка содержательной рецензии

Источник условий — `lessons/*/tasks.json`, решений — `solutions/TaskNN.cs`,
заготовок — `templates/Tasks.cs`. Генератор документов сохраняет существующие
заготовки. `TASK_REVIEW.json` содержит отдельную рецензию каждого задания:
условие, навык, отличие, решение, заготовка, тесты и изменения.

`reviewed_sha256` связывает рецензию с текущими условием, эталонным исходником и
извлечённой заготовкой. После изменения материалов сначала заново проверьте
соответствующую цепочку, обновите текст рецензии и только затем её хеш. Формула
канонизации находится в `tools/audit_course.py`; автоматически подтверждать
новое содержание одним пересчётом хеша нельзя. `audit_course.py` обнаруживает
устаревшие рецензии, но содержательность вывода проверяет человек или рецензент.
