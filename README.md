# Курс по основам C#

Практический маршрут от первой программы до консольного приложения с JSON-хранилищем и тестами.
Материалы универсальны и рассчитаны на начинающего: 16 модулей, 240 задач, три уровня сложности.
Курс использует .NET 10 LTS и C# 14; новые возможности языка вводятся по необходимости.

## С чего начать

1. Настройте [среду](docs/ENVIRONMENT_SETUP.md).
2. Откройте [первый урок](lessons/lesson_01_basics/README.md).
3. Пройдите цикл: теория → пример → собственное решение → проверка → разбор.
4. Выбирайте задачи через [единый задачник](docs/TASK_INDEX.md).
5. После урока 15 соберите [итоговый каталог книг](capstone/SPEC.md) и защитите его по критериям.

```powershell
git clone https://github.com/MaximillianVoss/csharp-intro-course.git
cd csharp-intro-course
dotnet build "Курс CSharp.slnx" -c Release
dotnet run --project "lessons/lesson_01_basics/examples/Урок01.Примеры.csproj"
dotnet test "capstone/Библиотека.Тесты/Библиотека.Тесты.csproj" -c Release
```

При первой сборке нужен интернет для восстановления MSTest.
Обычные уроки и приложение не используют внешних пакетов.
Python нужен только сопровождающему для проверки/обновления учебного каталога.

## Как устроены материалы

В каждом уроке:

- `THEORY.md` — объяснение понятий, примеры и самопроверка;
- `TASKS.md` — самостоятельные условия без решений;
- `SOLUTIONS.md` — ответы, ход решения, полный исходник и объяснение проверок;
- `examples/` — запускаемый пример;
- `solutions/TaskNN.cs` — отдельное проверяемое решение каждой задачи;
- `templates/Tasks.cs` — компилируемые рабочие места без ответов.
- `TASK_REVIEW.json` — индивидуальная проверка условия, решения, заготовки и тестов.

Заготовка по умолчанию показывает список задач. Вызов незаполненной задачи завершается ошибкой:
успешная компиляция заготовки не означает решённую задачу.

В сравнении с ориентиром C++ (650 задач в локальном расширенном варианте) выбран меньший банк:
240 задач покрывают 16 тем и разные виды мышления. Замена имён или чисел не считается новой задачей.
Итоговый проект и его этапы идут дополнительно к банку.

Для Visual Studio 2026 откройте `Курс CSharp.slnx`; решение `Практика CSharp.slnx` содержит только заготовки.
Первый раз запускайте конкретный проект, а не всё решение сразу.

Правообладатель пока не выбрал отдельную лицензию на публичное переиспользование.
Материалы опубликованы для изучения и прохождения курса; вопросы дальнейшего распространения согласуются с владельцем.
